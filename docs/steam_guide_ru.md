# Cortex-Command Steam ModManager 🛠️

Испытываете проблемы с работой модов из Steam Workshop в Cortex Command? Встроенная система модов может работать нестабильно, а иногда загруженные модификации `.rte` просто отказываются появляться или активироваться корректно.

**Cortex-Command Steam ModManager** — это легковесное WPF-приложение с открытым исходным кодом, созданное специально для обхода сломанной интеграции Steam Workshop. Оно автоматически находит моды, на которые вы подписались в Steam, определяет папку с игрой и безопасно устанавливает их именно туда, где они должны быть!

## 🚀 Особенности
- **Авто-обнаружение:** Автоматически находит директорию установки Steam и корневую папку Cortex Command.
- **Глубокое сканирование Workshop:** Ищет все скачанные архивы `.rte.*` внутри директории Steam `userdata`.
- **Умная распаковка:** Безопасно извлекает содержимое Workshop `.zip` архивов в правильную структуру папок `.rte` внутри директории игры.
- **Включение/Отключение в один клик:** Просматривайте все найденные моды с их названиями и именами папок, используя чекбоксы для их мгновенной установки или удаления.
- **Мультиязычность:** Доступно на русском, английском, арабском, китайском и японском языках.
- **Ручные настройки:** Если менеджер не может найти директории автоматически, вы всегда можете задать пути вручную через меню настроек.

## 📥 Как использовать
1. Скачайте последний релиз из нашего репозитория GitHub/GitLab.
2. Запустите исполняемый файл `CortexCommandModManager.exe`.
3. Приложение автоматически начнет поиск игры и модов.
4. Отметьте чекбокс рядом с модом, чтобы установить его, или снимите отметку для удаления из папки игры.
5. Запустите Cortex Command и наслаждайтесь игрой с модами!

## ⚙️ Настройки
Нажмите на иконку "Шестеренки" в правом верхнем углу, чтобы открыть меню настроек. Здесь вы можете:
- Вручную настроить пути к `Steam` и `Cortex Command`.
- Сбросить пути к авто-обнаруженным настройкам по умолчанию.
- Очистить внутренний конфигурационный файл менеджера модов.
- Изменить язык интерфейса с помощью иконки Глобуса рядом с шестеренкой.
